# Amazon India Dashboard

A responsive, single-page business dashboard for reviewing sales, profit, products, order status, payment methods, fulfilment, and state performance.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. For example:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Data

The figures in `app.js` are illustrative sample data for demonstration only. Replace the monthly totals and distribution arrays with verified seller data before using this dashboard for business decisions. The reporting-period selector updates the KPIs and charts from the monthly sample figures.
